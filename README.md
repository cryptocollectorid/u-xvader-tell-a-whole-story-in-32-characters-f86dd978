## The name

> IChangedTheLocksNotTheWiFi

26 characters. A Wi-Fi network name that lands a joke and implies a whole
story in the few words a passer-by sees in a phone's network list.

## Why this name

Someone changed the locks to keep a person out — and forgot the Wi-Fi.
The joke lands on the first read (the lockout was thorough, except for the
one thing that actually matters), and the name carries a whole story behind
it: a breakup, a first-person narrator, a door that no longer opens, and
the ex still sitting on the network from the car outside.

Against the judge's five criteria, in order:

1. **A Wi-Fi name, not a slogan** — it reads exactly like something a
   neighbour's router would be called, 26 characters, no filler.
2. **The joke lands in one read** — "changed the locks, not the Wi-Fi" is
   a twist a stranger gets without explanation.
3. **A whole story** — a situation (a lockout), a character (the "I" who
   changed the locks), and something that happened (the Wi-Fi password
   never got changed). The reader fills in the rest: the ex, the new
   locks, the signal still reaching the street.
4. **Fresh** — it is not one of the stock Wi-Fi jokes (no FBI van, no
   "Pretty Fly", no "It Burns When IP"). The lockout angle is a domestic
   story, not a recycled punchline.
5. **Tight** — every word earns its place; 26 of 32 characters, readable
   and easy to say out loud.

## Run it

```sh
python3 main.py
```

Writes the name to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Stdlib only, no network, no dependencies.
